# Asif Mehraj | Portfolio

Personal portfolio built with React, Vite and GSAP.

**Live:** [add link] | **GitHub:** https://github.com/ASIF-MEHRAJ

## Tech Stack
React · Vite · GSAP · CSS3 · Web Audio API

## Features
- GSAP preloader with curtain-split reveal
- Custom cursor
- 3D project carousel
- Scroll and text-roll animations
- Sound effects built with the Web Audio API
- Animated tech stack section
- Contact section with social links
- Responsive on desktop, tablet and mobile

## Run Locally
```bash
git clone https://github.com/ASIF-MEHRAJ/[repo-name].git
cd [repo-name]
npm install
npm run dev
```

## Build
```bash
npm run build
```
